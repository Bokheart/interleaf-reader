# Interleaf Reader — AI Workflow Protocol

**Status:** Superseded on 2026-06-20

This file no longer defines the standard AI workflow for Interleaf Reader.

For ordinary repository work, read:

1. `AGENTS.md`
2. `docs/PROJECT_STATE.md`
3. task-specific files

Read additional control documents only when required by the task, as defined in `AGENTS.md`.

Milestone scope and change control are maintained in:

```text
docs/MILESTONES.md
```

Durable product, architecture, compatibility, privacy, licensing, and governance decisions are maintained in:

```text
docs/DECISION_LOG.md
```

The historical protocol is preserved at:

```text
docs/archive/AI_WORKFLOW_PROTOCOL_2026-06-20.md
```

Interleaf Reader does not currently maintain a separate mandatory advanced AI workflow supplement.

If a future task explicitly requires multi-agent coordination, autonomous execution, recovery control, or a milestone harness, that workflow must be scoped for that task and must not override `AGENTS.md` or `docs/MILESTONES.md`.
