## 2. 产品摘要

**Interleaf Reader** 是一款**本地优先**的英文小说与长篇阅读 PWA，面向非母语英语读者。用户自行导入 EPUB，在受控的浏览器阅读环境中获得轻量词汇辅助——下划线、点击气泡、章节级词汇预习（Vocabulary Preview）——无需为了查词或背单词而跳出故事。

**核心使命：** 帮助用户在享受英文小说的同时自然理解剧情，并在阅读过程中逐步吸收词汇。

**MVP（当前产品目标）：** 英语学习模式 + EPUB 导入 + 章节导航 + Home / Reader / Vocabulary Library 视图 + 本地书库（Local Library）+ IndexedDB 本地持久化 + 滚动进度恢复 + 移动端阅读浮层 + Vocabulary Preview 与词汇气泡 + 等级基线过滤 + 用户词汇档案（已掌握 / 存入生词本 / 不再提示）+ 手动添加词汇 + 词汇导出（Copy Learning、Copy All、CSV 下载）。**中文阅读模式**与**混合模式**目前仅为**占位**，**不属于** MVP 交付范围。

**MVP 之后方向：** 与具体厂商无关的翻译架构、中文/混合阅读模式、全书翻译工作流（内部按章节/块队列 + 本地缓存）、更丰富的词汇增强、完整 PWA 可安装性、GitHub Pages 部署、开源发布与治理文档。

### 命名说明

“Interleaf” 让人联想到书页、叶片，以及语言之间的分层阅读。它契合规划中的英中混合阅读体验，例如：`Dean opened 门。`

### 定位陈述

Interleaf Reader 是一款**阅读应用**，词汇与翻译能力服务于沉浸式阅读。它**不是**背单词应用、**不是**通用翻译器、**不是**社交阅读平台。

## 4. 问题与机会

### 问题

喜爱英文小说与长篇的非母语读者，常常需要**离开阅读器**查词——打开词典、浏览器翻译或背单词 App。这会打断叙事节奏、增加疲劳，把娱乐阅读变成“作业”。

**浏览器翻译**有助于理解剧情，但无法在文本内提供结构化、由读者控制的词汇学习。**普通词汇 App** 为打卡与词卡优化，而非章节语境、同人小说节奏或“再看一章”的阅读动机。

### 机会

构建**阅读优先的支持层**：以英文原文为主，每章只呈现最有用的词汇，让读者保存真正关心的词；MVP 之后再用中文模式与混合模式辅助理解——而不把产品变成翻译工具。

## 5. 目标用户与画像

### 主要用户

- **非母语英语小说 / 长篇读者**（约 **14 岁以上**），具备一定英语基础。
- 通过**娱乐内容**学习——小说、网文、同人仅为用例之一，非唯一市场。
- 希望在**不离开故事**的前提下获得语境化词汇帮助。

### 画像（示例）

| 画像 | 需求 |
|---|---|
| **备考雅思的小说读者** | 标出雅思有用词汇，但不淹没每一行 |
| **同人 / 网文读者** | 轻量解释俚语、习语、圈内用语；人名可隐藏 |
| **回访读者** | 恢复章节与滚动位置；本地书架 |

### 仅未来考虑（非 MVP）

- **儿童友好版本** — 简化过滤与适龄 UX；产品形态（独立版 / 模式 / 子产品）**待定**。
- **青少年学习者** — 个性化规划中有提及；可能与未来调优相关。

## 6. 目标与非目标

### 产品目标

1. 提供平静、移动优先的英文小说 EPUB 阅读体验。
2. 通过 Preview、下划线、轻量气泡降低生词摩擦。
3. 让用户在本地建立**阅读衍生**的 Vocabulary Library（生词本）——保存、浏览、导出，而非打卡背诵。
4. 本地持久化书籍与进度（IndexedDB）；MVP 无需账号。
5. 为 MVP 之后的翻译模式与 Translation Provider 架构做准备。

### 非目标

- 词汇背诵产品（间隔重复、词卡、游戏化打卡）。
- 通用全文翻译器或专业翻译服务替代品。
- 社交阅读（评论、书架分享、读书会）。
- 托管版权书籍或公开译本。
- MVP 阶段的云同步、账号、跨设备书库。

### MVP 目标

交付可信的**英语学习模式**纵向切片：导入 → 阅读 → 词汇辅助 → 保存/导出 → 续读，全部本地优先。

### MVP 之后目标

- 中文阅读模式与混合模式的真实翻译输出。
- Translation Provider 设置与安全 API key 处理。
- 词汇增强、舒适度等级引导 UI、真正的「学习 → 掌握留档」生命周期。
- 完整 PWA、GitHub Pages 部署、开源治理、可选本地伴随服务。

## 7. 核心用户旅程

| 旅程 | MVP 状态 | 摘要 |
|---|---|---|
| **导入 EPUB** | 已实现 | 拖放或选择文件 → 诊断 → 章节列表 → 阅读 |
| **带提示读英文** | 已实现 | 英语学习模式、纵向滚动、下划线 + 气泡 |
| **使用 Vocabulary Preview** | 已实现 | 侧栏 / 移动端底部面板；已掌握 / 存入生词本 / 不再提示 |
| **保存词汇** | 已实现 | 存入生词本 → `learningWords`；Vocabulary Library 视图 |
| **管理本地书库** | 已实现 | Home 列表；打开 / 遗忘；IndexedDB 恢复 |
| **导出词汇** | 已实现 | Copy Learning、Copy All、Download CSV |
| **翻译书籍 / 切换模式** | MVP 之后 | 中文 / 混合模式现为占位；真实翻译待实现 |

### MVP 阅读闭环

1. 用户打开应用（静态网页 URL）。
2. 导入 EPUB 或从本地书库继续。
3. 进入 Reader，恢复章节与近似滚动位置。
4. 阅读英文；需要时点击下划线查看气泡。
5. 打开 Vocabulary Preview，标记已掌握 / 存入生词本 / 不再提示。
6. 可选进入 Vocabulary Library 手动添加或导出。
7. 返回 Home；书籍与进度保留在本浏览器。

## 8. 核心阅读模式

### 模式对照

| 模式 | 说明 | 示例 | 状态 |
|---|---|---|---|
| **英语学习模式**（English Study Mode） | 英文原文 + 轻量词汇帮助 | `Dean opened the door.` — *door* 可下划线，点击气泡 | **已实现** |
| **中文阅读模式**（Chinese Reading Mode） | 中文翻译帮助理解剧情 | `Dean打开了门。` | **占位** |
| **混合模式**（Mixed Mode） | 中文语境中保留部分英文词/短语 | `Dean opened 门。` | **占位** |

**工程备注：** 代码与部分文档使用 **Cloze Mixed Mode**（`cloze-mixed`）。面向用户的文案应优先使用 **混合模式**。

### 模式切换行为（当前）

- 切换模式时保留书籍、章节与近似滚动位置。
- 占位模式不得表现为换章或错误重置进度。
- MVP 价值完全由英语学习模式交付。

### 9.5 Vocabulary Preview 与词汇气泡

| | |
|---|---|
| **目的** | 章节级词汇推荐与文内轻量查词。 |
| **当前状态** | **已实现**（精选种子数据集；个性化为部分实现） |
| **需求** | 匹配 `vocabulary.json` + `slang_idioms.json`；生成 Preview；HTML 内下划线；点击气泡显示词项、中文释义、英文定义与雅思用法（若有）；同词再点关闭、换词切换；Preview 比气泡信息更丰富；Preview 操作：已掌握 / 存入生词本 / 不再提示；已保存词显示 Saved 标记。 |

### 9.6 词汇档案与 Vocabulary Library（生词本）

| | |
|---|---|
| **目的** | 本地持久化用户词汇决策并支持导出。 |
| **当前状态** | **已实现**（v1 语义） |
| **需求** | IndexedDB 档案：`selectedLevel`、`knownWords`、`learningWords`、`ignoredWords`、`preferredCategories`、`updatedAt`；等级基线 JSON `level1`–`level5` 用于有效已知词过滤；Vocabulary Library 标签页；手动「添加到学习中」；行级删除；导出 Copy Learning、Copy All、CSV（`term,status`）。 |
| **完成标准** | 已掌握/存入/不再提示跨会话持久；导出列表正确。 |

#### v1 词汇语义（canonical）

| 操作 | 含义 | 存储 | Preview | 生词本标签 |
|---|---|---|---|---|
| **已掌握**（Known） | 本来就认识该英文词 | `knownWords` | 隐藏 | **Mastered**（v1 归档标签） |
| **存入生词本**（Save） | 想学习/保留 | `learningWords` | 保持可见；Saved 标记 | **Learning** |
| **不再提示**（Hide） | 非学习目标 | `ignoredWords` | 隐藏 | **Hidden** |
| **掌握留档**（Mastered，v1） | 与「已掌握」归档相同 | `knownWords` | — | **Mastered** 标签页 |

**MVP 之后：** 真正的**学习 → 掌握留档**生命周期（与「已掌握」区分）；词条释义/例句；来源书名/章节；复习模式；Anki/JSON 导出；批量导入。

**说明：** Vocabulary Library 是**阅读衍生的词汇集合**，不是词卡或背诵打卡产品。MVP 无间隔重复。

## 10. 体验原则

1. **移动优先阅读** — 窄屏全宽正文；次要面板用底部面板。
2. **低打扰** — 点击「已掌握」不必每次弹模态；后续可用轻提示。
3. **轻量气泡** — 字段简短；丰富信息留在 Vocabulary Preview。
4. **Preview 有帮助但不淹没** — 条数有上限；非每个未知词都展示。
5. **阅读始终是主角** — 词汇从属于正文。
6. **个性化失败开放** — 可选模块懒加载；EPUB 导入与章节渲染不依赖它们。
7. **占位诚实** — 中文/混合模式不得伪装已翻译。
8. **本地透明** — 安静说明数据留在本设备/本浏览器。

## 11. 数据与隐私

| 主题 | MVP 政策 |
|---|---|
| **存储** | IndexedDB（书籍、进度、词汇档案）；少量 `localStorage` 元数据 |
| **本地优先** | 无账号；MVP 无云同步 |
| **用户内容** | 用户自备 EPUB；本地存储 |
| **托管内容** | 应用不托管版权书籍或公开译本 |
| **词汇种子数据** | 精简 JSON；不把源 PDF 全文复制进数据集 |
| **CDN** | 当前 epub.js / JSZip 来自 CDN — 第三方请求；须在 PRIVACY（**待定**）中说明 |
| **API key** | 用户密钥不得进入仓库；翻译向 Provider 发送章节文本 — 流程在隐私文档中 **待定** |
| **分析统计** | MVP 不强制 — 若后续添加则 **待定** |

**未来：** 档案导入/导出作为无账号的轻量同步。

## 12. 技术架构与约束

### 技术栈（当前）

- 静态 Web 应用 — 无构建步骤
- 浏览器 ES 模块：`app.js`、`epubLoader.js`、`vocabEngine.js`、`levelBaselineEngine.js`、`storage.js`、`readingModes.js`、`translationEngine.js`、`glossaryEngine.js`、`navigationEngine.js`
- epub.js + JSZip（CDN）
- IndexedDB 持久化
- 纯逻辑 Node 测试（`tests/*.test.mjs`）

### 模块边界

| 模块 | 职责 |
|---|---|
| `app.js` | UI 状态、视图、事件、编排 |
| `epubLoader.js` | 仅 EPUB 解析/加载 |
| `vocabEngine.js` | 词汇匹配、Preview、HTML 标注 |
| `levelBaselineEngine.js` | 基线 + 有效已知词 |
| `storage.js` | IndexedDB + 档案辅助函数 |
| `readingModes.js` | 模式渲染决策 |
| `translationEngine.js` | 未来 Provider 边界 |

### 硬性约束

1. **前端自有代码中不得包含 API key。**
2. **可选模块**（个性化、翻译）必须懒加载并安全回退。
3. **EPUB 导入与章节渲染**是主路径 — 不得被可选功能阻塞。
4. **不得**在浏览器 bundle 中用明文密钥实现 DeepL（或任何付费 Provider）。
5. 保持纯逻辑可测；避免 `app.js` 无限膨胀。

### 建议的代理规则（摘要）

## 18. 术语表

| 术语 | 定义 |
|---|---|
| **PWA** | 渐进式 Web 应用；完整可安装性 **计划中** |
| **EPUB** | 标准电子书格式；用户导入；经 epub.js 解析 |
| **IndexedDB** | 浏览器数据库；存 EPUB、进度、词汇档案 |
| **本地书库**（Local Library） | 本设备已保存的 EPUB（元数据 + 二进制） |
| **词汇预习**（Vocabulary Preview） | 章节级推荐学习词列表 |
| **生词本 / Vocabulary Library** | 用户持久词表（Learning / Mastered / Hidden）— 阅读衍生，非打卡 |
| **英语学习模式**（English Study Mode） | 英文原文 + 词汇叠加 — **MVP 核心** |
| **中文阅读模式**（Chinese Reading Mode） | 全章中文理解剧情 — **占位** |
| **混合模式**（Mixed Mode） | 以中文为主、保留部分英文 — **占位** |
| **翻译提供方**（Translation Provider） | 可插拔机器翻译后端 — **计划中** |
| **受保护词表**（Protected Terms / Glossary） | 翻译中保留的专名、圈内词等 |
| **已掌握**（Known） | 用户已认识；Preview 隐藏；存 `knownWords` |
| **存入生词本**（Save） | 加入学习列表（`learningWords`） |
| **不再提示**（Hide） | 非学习目标（`ignoredWords`） |
| **掌握留档**（Mastered，v1） | UI 上 Mastered 标签页对应 `knownWords` 归档 — 非学后掌握流程 |
| **本地优先**（Local-first） | 数据在设备上；MVP 无云账号 |
| **API key** | 用户或部署方为 Translation Provider 提供的凭证 — 不得出现在公开前端代码中 |
